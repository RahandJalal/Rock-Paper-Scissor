# ✊ Rock Paper Scissors Game

A classic Rock-Paper-Scissors web game where players compete against a randomized computer opponent with live score tracking.

---

## ✨ Features

- **Player vs Computer:** Randomized opponent choice logic.
- **Live Scoreboard:** Real-time round updates, score counter, and winner declarations.
- **Interactive UI:** Smooth transitions and click-responsive icons.

---

## 🛠️ Built With

- **HTML5:** Game layout and interface elements.
- **CSS3:** Clean styling and responsive layout.
- **JavaScript (ES6):** Game state management, conditionals, and DOM manipulation.
